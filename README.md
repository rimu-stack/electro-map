# Редактор графов

Интерактивный редактор графов на React с использованием React Flow и Tailwind CSS.

## Возможности

- ✨ Создание узлов различных форм (прямоугольник, круг, ромб, эллипс, точка)
- 🔗 Создание и управление связями между узлами с 4 точками подключения (сверху, снизу, слева, справа)
- 🎨 Настройка цвета и свойств узлов
- 📝 Добавление пользовательских параметров для каждого узла и ребра
- 🖱️ Интуитивное управление: перетаскивание, масштабирование, панорамирование
- 🗑️ Удаление узлов и рёбер (кнопка Delete или через панель свойств)
- 💾 Экспорт данных для отправки на бекенд

## Установка

1. Установите зависимости:
```bash
npm install
```

## Запуск

Запустите dev-сервер:
```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

## Использование

### Создание узлов
- Дважды кликните на пустое место холста для создания нового узла
- Выберите форму узла на верхней панели инструментов перед созданием

### Создание связей
- Наведите курсор на узел
- Потяните от одной из 4 точек соединения (сверху, снизу, слева или справа) к другому узлу

### Редактирование свойств
- Кликните на узел или ребро для отображения панели свойств справа
- Измените метку, описание, цвет и другие параметры
- Добавьте пользовательские параметры кнопкой "+ Добавить параметр"

### Удаление элементов
- **Через клавиатуру**: Выберите элемент и нажмите Delete/Backspace
- **Через панель свойств**: Нажмите кнопку "🗑️ Удалить"

### Управление холстом или используйте кнопку в панели свойств
- **Перемещение узлов**: Перетащите узел мышью
- **Перемещение холста**: Зажмите пробел и перетащите мышью
- **Масштабирование**: Используйте колесико мыши или кнопки +/- в правом нижнем углу
- **Удаление**: Выберите элемент и нажмите Delete/Backspace

### Экспорт данных
- Выберите узел или ребро
- Нажмите кнопку "Экспортировать данные" в панели свойств
- Данные будут выведены в консоль браузера

## TLS режимы в Docker (Traefik)

В `docker-compose.yml` теперь доступны два режима HTTPS:

- ACME (Let's Encrypt) — режим по умолчанию, как и раньше
- Self-signed — дополнительный режим для локальной разработки

### ACME (по умолчанию)

Если не задавать переменные, используется `ACME_HOST=md.localhost` и ACME-роутеры.

### Self-signed (дополнительный)

1. Сгенерируйте самоподписанный сертификат:

```bash
mkdir -p certs traefik/dynamic && \
openssl req -x509 -nodes -newkey rsa:2048 -days 365 \
  -keyout certs/local.key \
  -out certs/local.crt \
  -subj "/CN=md.localhost" && \
cp traefik/tls.selfsigned.yml.example traefik/dynamic/tls.yml
```

2. Запустите в self-signed режиме:

```bash
SELF_SIGNED_HOST=md.localhost ACME_HOST=acme.disabled.local docker compose up -d --build
```

`SELF_SIGNED_HOST` включает роутеры без `certresolver`, а `ACME_HOST` уводим на неиспользуемый host, чтобы не было конфликтов правил.

## Формат данных для бекенда

Каждый узел имеет следующую структуру:
```json
{
  "id": "node-1",
  "type": "node",
  "data": {
    "label": "Название узла",
    "description": "Описание",
    "color": "#3b82f6",
    "shape": "rectangle",
    "customParam": "значение"
  }
}
```

Каждое ребро:
```json
{
  "id": "edge-1",
  "type": "edge",
  "data": {
    "label": "Название связи",
    "weight": 1,
    "customParam": "значение"
  }
}
```
